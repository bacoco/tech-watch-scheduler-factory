# Tests

`test_profiles.py` : décisions de sources, preuves et profils.
`test_render.py` : génération, déduplication, batch, intégrité.
`test_state.py` : T0, couverture, gel et modifications détectées.
`test_updates.py` : reprises, parent attendu et curseurs.
`test_install.py` : installation réelle dans des repos Git temporaires.
`test_github.py` : réseau simulé et collecte factuelle bornée.
`support.py` : fixtures synthétiques partagées.

Aucun test n'utilise de token, ne publie d'issue ni ne crée de repo distant.
Ces tests prouvent le comportement local du code, pas une recherche réelle.

Le test du README préserve les demandes copiables en langage naturel, sans commande technique.
