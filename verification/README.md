# Preuves de vérification

[Contrôles locaux du 7 septembre 2026](local-2026-09-07.json) : commandes,
résultats et empreinte de l'archive v0.2.0 d'origine.

Les tests utilisent des exemples de recherche synthétiques et des réponses
réseau simulées. Ils contrôlent la mécanique, pas la qualité d'une recherche réelle.
Les checks CI distants sont consultables dans l'onglet Actions du dépôt.
Le SHA de la branche publiée doit être vérifié séparément après le push.

Aucun test ne prouve qu'une tâche ChatGPT a été créée, qu'un repo cible a reçu
son profil ou qu'un T0 réel a été effectué. Voir [la livraison](../DELIVERY.md).
