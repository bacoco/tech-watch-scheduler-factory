# Exemple et portefeuille

`image-product.json` est un profil SYNTHÉTIQUE pour tester la génération.
Il ne prouve aucune lecture de code réel et ne doit jamais être installé dans
un repo utilisateur sans refaire l'analyse et remplacer les preuves.
Le renderer ne transforme pas une fixture en audit.

`bacoco-selection.json` donne seulement des noms de cibles proposés d'après
la demande et l'étude préalable. Ce n'est ni un classement courant ni une
preuve de disponibilité. Une invocation doit redécouvrir les dates et branches.

`domain-watch.json` illustre une veille d’information sans modification de code.
Ses sources et parcours restent SYNTHÉTIQUES, comme ceux de image-product.json.
